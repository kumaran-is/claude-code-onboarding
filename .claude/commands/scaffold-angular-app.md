# Scaffold Angular SPA

**App name:** $ARGUMENTS (default `my-app`)

| Package | Version |
|---|---|
| `@angular/cli` (creator) | `21.2.30` |
| `@angular/*` | `~21.2.x` (tilde: experimental APIs such as resources/Signal Forms can change in a minor) |
| TypeScript | `~5.9.2` (from `ng new`) |

## Pre-requisites

1. Read the `angular-spa` skill (`SKILL.md`, `reference/angular-templates.md`, `reference/web-security.md`,
   `reference/testing-vitest.md`) and the `angular-ui-patterns` skill.
2. After step 1 below, call `mcp__angular-cli__get_best_practices` **with `workspacePath`** = the new
   project folder. Without the path the tool returns v22 guidance, which is wrong for this 21.2 app.
   If the path is refused (outside the client's roots), say so and rely on the skills and `.d.ts` files.

## Steps

1. **Create the workspace** (the `CC_SCAFFOLD=` prefix is the per-command authorization
   `block-raw-scaffold.sh` requires):
   `CC_SCAFFOLD=scaffold-angular-app npx @angular/cli@21.2.30 new <name> --style=css --ssr=false --skip-git --defaults`
   Global styles are CSS because Tailwind 4 is configured in `src/styles.css`.
2. **Tighten Angular ranges** — in `package.json` change every `"@angular/…": "^21.…"` to `"~21.…"`, then `npm install`.
3. **TailwindCSS 4 + daisyUI 5.5.5** —
   `npm install --save-exact tailwindcss@4.3.5 @tailwindcss/postcss@4.3.5 postcss@8.5.33 daisyui@5.5.5`;
   create `.postcssrc.json` with `{ "plugins": { "@tailwindcss/postcss": {} } }`; `src/styles.css`:
   `@import "tailwindcss";` then `@plugin "daisyui";` (details: `reference/tailwind-v4-config.md`).
4. **Lint** — `npx ng add angular-eslint@21.4.0 --skip-confirmation` (adds the `lint` target; `ng new` has none).
5. **Folders** — `core/{auth,config,http,logging}/`, `shared/components/`, `features/dashboard/`.
6. **`app.config.ts`** — exactly the `angular-templates.md` §app.config.ts shape: no zone provider,
   `provideRouter(routes, withComponentInputBinding())`, `provideHttpClient(withFetch(), withInterceptors([authInterceptor]))`,
   an `API_CONFIG` provider with the API origin(s) allowed to receive credentials.
7. **Auth** — copy `authInterceptor` (allow-listed origins only, single-flight refresh, one retry,
   no refresh on 403), `AuthSession` (in-memory token, HttpOnly refresh cookie), `signedInGuard`
   (waits for session restore) and `safeReturnUrl` from `reference/web-security.md`. No stubs, no
   tokens in `localStorage`. Comment that guards are UX and the API authorizes.
8. **Typed error model + logger** — `core/http/api-error.ts` (`ApiError`, `toApiError`) and
   `core/logging/logger.ts` from `angular-ui-patterns/reference/error-handling.md`. No `console.*` elsewhere.
9. **Dashboard feature** — a service (`DashboardApi`, typed, errors propagate) and a page that reads it
   with `rxResource` (label it EXPERIMENTAL in a comment) and renders **four states**: loading
   (`role="status"`), empty, error (`role="alert"`, message from `ApiError.kind`, retry except for
   401/403) and success. When the backend is absent the page shows the **error state with retry** —
   never fallback, static or mock data.
10. **Routes** — lazy `loadComponent`, root redirect to `dashboard`, `canActivate: [signedInGuard]`
    on protected routes, `title` per route, a real not-found page for `**`.
11. **Environment** — `src/environments/environment.ts` holds only public values (API origin). It ships
    to every browser: no secrets.
12. **Tests** (`reference/testing-vitest.md`) — Dashboard spec covering loading, empty, error (403 and
    5xx) and success with `HttpTestingController` (flush before `whenStable()`); interceptor spec
    (no credentials to a look-alike host; one refresh for concurrent 401s; no loop); guard spec with
    `RouterTestingHarness`. No `fakeAsync`.
13. **Verify** — run each and report its own exit code:
    ```bash
    npx ng test --watch=false; echo "test exit=$?"
    npx ng build; echo "build exit=$?"
    npx ng lint; echo "lint exit=$?"
    ```
    Any non-zero exit → fix before finishing. E2E (optional): Playwright via the `browser-testing` skill.
14. **Summary** — created files, the three exit codes, how to run (`npm start`), next steps.
